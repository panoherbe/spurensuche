# Dilemma

**Kurz:** Eine echte Streitfrage zum Ort. Die Gruppe hört verschiedene Meinungen, stimmt ab, begründet ihre Entscheidung und
sieht, was passieren könnte und was wirklich geschah. Es gibt keine falsche Entscheidung, nur passende und unpassende
Begründungen.

## Ablauf (fünf Schritte)

1. **Lesen:** die Lage mit Foto und die Frage.
2. **Meinungen hören:** vier bis acht Meinungen typischer, erfundener Personen (`argumente`, jede spricht für genau eine
   Möglichkeit). Die Seiten stehen nicht dabei: Die Gruppe wägt selbst ab.
3. **Abstimmen:** Stimmen je Möglichkeit zählen, ohne Namen. Bei Gleichstand redet die Gruppe noch einmal.
4. **Begründen:** Meinungen wählen, die die Entscheidung stützen. Passt eine nicht, sagt das Spiel, welche, und die Gruppe
   prüft noch einmal. Danach: Welche Meinung der Gegenseite nehmt ihr trotzdem ernst? (freiwillig)
5. **Folgen:** „So könnte es weitergehen“ für die eigene Wahl, aufklappbar für die andere, und „So war es wirklich“.

## Sammelstück und Sterne

- Jede Gruppe, die eine passende Begründung abgibt, bekommt **jedes** Sammelstück aus `belohnung`.
- Sterne: 3, wenn die Gruppe begründet **und** eine Meinung der Gegenseite ernst nimmt; 2 mit Begründung.

## Ereignisse

| Art | wann |
|---|---|
| `abstimmung` | `einig` (alle Stimmen für eine Möglichkeit) oder `mehrheit` |
| `weg` | Kennung der gewählten Möglichkeit |
| `versuch` | `true` bei passender Begründung, `false`, wenn eine gewählte Meinung zur anderen Seite gehört |
| `neuer-anlauf` | erste Änderung nach einer unpassenden Begründung: `true`, wenn die Gruppe eine der unpassenden Meinungen herausnimmt oder einen Tipp holt |
| `hilfe` | Tippstufe 1–3 (Texte aus der Aufgabe) |
| `rolle` | `steuern` (Stimmen, Meinungen wählen), `pruefen` (Auswerten, Abgeben, Weiter), `nachschlagen`, `vorlesen` |
